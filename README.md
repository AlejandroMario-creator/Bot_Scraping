# Web Scraper de Libros automatizado con Python

Este proyecto consiste en un **bot de web scraping** desarrollado en Python dentro de un entorno de Google Colab. El bot está diseñado para navegar de forma autónoma por el catálogo de [Books to Scrape](https://books.toscrape.com/), extraer información detallada de los libros y exportar los resultados a un archivo `.csv` estructurado.
